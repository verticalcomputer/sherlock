# Security policy

Report suspected Sherlock security vulnerabilities privately to
[akash@vertical.computer](mailto:akash@vertical.computer), the security contact
provided by Vertical Computer Inc.

Include the affected version or commit, relevant component, impact and concise
reproduction steps. Redact credentials and customer information. Do not post
unreported vulnerability details, secrets or customer telemetry in public issues.

## Release status

Sherlock source is public under Apache-2.0. A source checkout or unsigned preview
build is not an approved signed client release. See [current release status](next.md). A supported-version policy will
be published with the first approved release; no maintenance or response-time
commitment is stated here.
