# Experimental GPU cooling assessment

This package is the pure v1 `gpu_cooling` category. Its versioned policy, tracker state, candidate state and details are strict canonical payloads. The shared assessment host owns deadlines, comparison arms, retention, recurrence identity and preview routing.

Discovery scans retained admission and source-eligibility events from the persisted discovery floor. A covered rapid or slow positive temperature change, or covered persistent warmth, establishes entry. Power corroboration is evaluated after entry. A separately qualified critical GPU or HBM thermal occurrence takes precedence. Optional utilization has no effect on v1 outcomes.

A persistent high temperature, or an original warming branch that still passes with stable power and sustained temperature, supports investigation. Reference-based settling requires covered intermediate endpoints and temperatures within the applicable range. Persistent-only settling checks every raw temperature against its recovery threshold over the covered settling interval. The physical tracker can select one rebound reference at entry or on the first eligible follow-up using covered power transitions. The reference cites its first materialized bundle. Arms use the tracker context available at their own cutoffs. Conflicting or incomplete evidence can prevent corroboration, transient classification and rearm.

A successful terminal quotes the newest supported, fresh temperature endpoint when available. That immutable reference is the baseline for a subsequent higher-temperature update. An independently qualified new urgent occurrence can warrant a follow-up even when a temperature baseline is unavailable. Rearm requires a covered interval. The tracker retains each unresolved critical occurrence observed during the sequence and requires its exact qualified recovery.

The profile and decisions are experimental. Replay fixtures establish policy behavior with supplied evidence. Live evidence cadence, detection quality, resource qualification and delivery require their own acceptance evidence.
